# Bundled terminal symbols

`symbols-nerd-font-mono-subset.woff2` is generated from Nerd Fonts Symbols
Only v3.4.0. The reproducible input URL, SHA-256, FontTools version and included
Powerline/Codicons Unicode ranges are pinned in
`../../scripts/vendor-nerd-symbols.sh`.

The original Nerd Fonts license is stored beside the generated subset. UI and
terminal text fonts come from locked `@fontsource/*` packages (OFL-1.1); their
license and source metadata are retained in `node_modules` and the lockfile.
